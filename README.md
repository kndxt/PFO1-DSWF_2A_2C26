Documentación del uso de IA:
Herramientas utilizadas: Claude.ai y Gemini (todas utilizadas en sus planes gratuitos)
La imagen del avatar fue realizada en https://picrew.me/en/image_maker/684058
Comencé explorando con diferentes prompts en Gemini y Claude para idear la estructura de la landing y definir la paleta de colores cyberpunk gótico. 
Fui manipulando y adaptando el código HTML y CSS manualmente para posicionar las secciones, ajustar el diseño responsivo y asegurar que la información sea accesible y legible.
Las vistas previas de "Mercado liebre", "PizzaRock" y la app del "Club Deportivo" fueron diseñadas y generadas con Gemini a modo ilustrativo, dado que las interfaces definitivas se encuentran en desarrollo o modeladas en entornos específicos.
Experiencia previa: Cuento con poca experiencia previa utilizando IA para maquetaciones web, habiendo experimentado previamente de forma básica con ChatGPT.
