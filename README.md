# PFO Nº1 - Desarrollo de Sistemas Web - Frontend
Landing de portafolio personal con HTML y CSS.

**URL del proyecto:** [https://mi-portfolio-omega-liart.vercel.app/](https://mi-portfolio-omega-liart.vercel.app/)

## Tecnologías Utilizadas
* **HTML5:** Semántica y estructura del sitio.
* **CSS3:** Estilos, Flexbox/Grid, variables personalizadas y diseño responsivo (Mobile First).
* **Despliegue:** Vercel.

## Documentación del uso de IA
**Herramientas utilizadas:** Claude.ai y Gemini (utilizadas en sus planes gratuitos).

* **Generación de código base:** El primer esqueleto del código HTML y CSS fue generado utilizando Gemini y Claude, sirviendo como punto de partida para el proyecto.
* **Ideación y Diseño:** Exploré diferentes prompts en Gemini y Claude para estructurar la landing y definir la paleta de colores temática (estilo cyberpunk gótico) pero que se vea profesional sin caer en lo amateuro o informal, teniendo en cuenta que lo puedo usar para futuras postulaciones laborales. 
* **Refinamiento manual:** Fui manipulando y adaptando el código generado manualmente para posicionar las secciones, ajustar el diseño responsivo y asegurar que la información sea accesible y legible.
* **Generación de recursos gráficos:** Las vistas previas de los proyectos ("Mercado liebre", "PizzaRock" y la app del "Club Deportivo") fueron diseñadas y generadas con Gemini a modo ilustrativo, dado que las interfaces definitivas se encuentran en desarrollo o modeladas en entornos específicos.
* **Avatar:** La imagen del avatar principal fue creada a través de [Picrew](https://picrew.me/en/image_maker/684058).

## Experiencia previa con IA
Especificamente para maquetaciones web, cuento con poca experiencia previa utilizando inteligencia artificial, anteriormente solo había experimentado de forma básica generando fragmentos con ChatGPT. Este proyecto representa mi primera integración completa de IA en el flujo de diseño y desarrollo frontend.
